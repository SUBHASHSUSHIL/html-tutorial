List Types

Demonstrates ordered lists, unordered lists, description lists, and nested (multi-level) lists with various list-style types.

1. Ordered List

The type attribute sets the numbering style: 1, a, A, i, I.

Default (1):

  1. Garments
  2. Footwears
  3. Food Items
  4. Electricals
  5. Others

Type = a:

  1. Garments
  2. Footwears
  3. Food Items
  4. Electricals
  5. Others

Type = I:

  1. Garments
  2. Footwears
  3. Food Items
  4. Electricals
  5. Others

Reversed:

  1. Garments
  2. Footwears
  3. Food Items
  4. Electricals
  5. Others

Start = 3:

  1. Food Items
  2. Electricals
  3. Others

2. Unordered List

The type attribute sets the bullet style: disc, circle, square, none.

Default (disc):

  • Garments
  • Footwears
  • Food Items
  • Electricals
  • Others

Type = circle:

  • Garments
  • Footwears
  • Food Items
  • Electricals
  • Others

Type = square:

  • Garments
  • Footwears
  • Food Items
  • Electricals
  • Others

Type = none:

  • Garments
  • Footwears
  • Food Items
  • Electricals
  • Others

3. Description List

A description list pairs terms (dt) with descriptions (dd).

MBA
Master of Business Administration
MCA
Master of Computer Applications
CA
Chartered Accountant

4. Nested List (Multi-Level)

Nesting a list inside a list item creates a multi-level list.

  • Garments
    1. Male
    2. Female
    3. Kids
  • Footwears
  • Food Items
  • Electricals
  • Others
