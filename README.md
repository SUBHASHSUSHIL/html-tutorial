## About This Repository

A collection of essential HTML concepts and examples to help developers
understand and implement various HTML elements, forms, tables, lists, links,
and more. Designed for beginners and experienced developers looking to
strengthen their HTML skills.

## Project Structure

```
html-tutorial/
├── index.html                       # Landing page linking to all examples
├── css/
│   └── style.css                    # Shared stylesheet for all pages
├── forms/
│   ├── student-form.html            # Basic form inputs (text, date, radio, checkbox)
│   ├── admission-form.html          # Comprehensive form with selects, datalists, validation
│   └── login-page.html              # Simple login form using a table layout
├── links/
│   ├── external-internal-links.html  # Text and image linking, anchor navigation
│   └── hyperlinking.html            # External and internal hyperlinking
├── lists/
│   ├── list-types.html              # Ordered, unordered, description, and nested lists
│   └── ordered-lists.html           # Ordered lists with various numbering types
├── tables/
│   └── student-table.html           # Data table with thead, tbody, tfoot, colspan
└── email-links/
    └── mailto-example.html          # Mailto link with prefilled email fields
```

## Topics Covered

- **HTML Structure & Basic Elements** — DOCTYPE, head, meta tags, semantic markup
- **Forms and Input Elements** — text, password, date/time, radio, checkbox, select, datalist, file, range, color
- **Tables** — caption, thead, tbody, tfoot, colspan, scope
- **Lists** — ordered, unordered, description, nested, international numbering styles
- **Links** — external, internal, text, image, target attributes, anchor navigation
- **Email Links** — mailto with CC, BCC, subject, and body parameters
- **Form Validation** — required, pattern, minlength, maxlength, min, max, step

## Technologies

- HTML5
- CSS3 (shared stylesheet with CSS custom properties)
