Mailto Link

The mailto: URL scheme opens the visitor's default email client with prefilled fields. You can set the recipient, CC, BCC, subject, and body via query parameters.

What is a mailto link?

A mailto link is a type of HTML link that activates the default mail client on the computer for sending an email. The web browser requires a default email client application installed in order to activate the email client.

Tip: Spaces should be encoded as %20 and line breaks as %0A to ensure the email client parses the URL correctly. The link will only work if the user has an email client installed.
